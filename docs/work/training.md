## How I approach training

- **Start from the task.** Each module is built around something the learner needs to do, not a list of features.
- **Reuse the documentation.** Training and documentation share the same terminology and source material, so they never contradict each other.
- **Show, then explain.** Video walkthroughs demonstrate the task first, then cover the reasoning behind each step.
- **Leave something to come back to.** Every module points to the documentation the learner will use afterwards.

## What this shows

- Producing video training end to end, from script to recording to LMS delivery
